## Get started

<Tabs>
  <TabItem label="In the browser" icon="laptop">
    Open the [hosted demonstration](https://platforms.xila.dev/), create or select a disk if prompted, then log in as **administrator** with an empty password. It needs a browser with OPFS and Web Locks.

    [Follow the browser tutorial →](/tutorials/browser/)

  </TabItem>
  <TabItem label="With Docker" icon="seti:docker">
    From a host terminal, pull the runtime, create a persistent volume, and open Xila's own command-line shell:

    ```sh
    docker pull ghcr.io/xila-project/xila-runtime:latest
    docker volume create xila-state
    docker run --rm -it --network none --read-only \
      --tmpfs /tmp:rw,noexec,nosuid,size=16m \
      --mount type=volume,src=xila-state,dst=/var/lib/xila \
      ghcr.io/xila-project/xila-runtime:latest
    ```

    [Run Xila with Docker →](/how-to/run-container-guest/)

  </TabItem>
  <TabItem label="Natively" icon="seti:rust">
    On x86_64 Linux with a Wayland session, build the guests and the filesystem image, then start the native desktop from the `platforms` checkout:

    ```sh
    mise run run:cargo -- -p xila-native-example --bin native_example -- \
      --gui --no-network --seed-image target/seed/native/seed.img
    ```

    [Follow the native tutorial →](/tutorials/native/)

  </TabItem>
</Tabs>

## Why Xila

<CardGrid>
  <Card title="Lightweight" icon="rocket">
    Optimized for embedded systems, ensuring high performance on
    resource-constrained hardware.
  </Card>
  <Card title="Safe" icon="approve-check">
    Built on Rust's memory-safety guarantees for a robust and secure execution
    environment.
  </Card>
  <Card title="Portable" icon="laptop">
    Abstracts hardware complexities to run across various architectures and
    boards.
  </Card>
  <Card title="Modular" icon="puzzle">
    Extend functionality dynamically with isolated WebAssembly modules.
  </Card>
</CardGrid>
