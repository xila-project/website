## Get started

<Tabs>
  <TabItem label="In the browser" icon="laptop">
    Open the [demonstration](/demonstration/), create or select a disk if prompted, then log in as `administrator` with an empty password. Requires a web browser supporting Origin Private File System (OPFS) and Web Locks. <DemonstrationLanguages />

    [Follow the browser tutorial →](/tutorials/browser/)

  </TabItem>
  <TabItem label="With Docker" icon="seti:docker">
    From a host terminal, pull the runtime image, create a persistent volume, and open Xila's interactive command-line shell:

    ```sh
    docker pull ghcr.io/xila-project/xila-runtime:latest
    docker volume create xila-state
    docker run --rm -it --network none --read-only \
      --tmpfs /tmp:rw,noexec,nosuid,size=16m \
      --mount type=volume,src=xila-state,dst=/var/lib/xila \
      ghcr.io/xila-project/xila-runtime:latest
    ```

    [Run Xila with Docker →](/how-to/run-xila-with-docker/)

  </TabItem>
  <TabItem label="Natively" icon="seti:rust">
    On x86_64 Linux with a Wayland session, generate the reference disk image and start the native runtime from the Platforms repository:

    ```sh
    cargo run -p xila-native-example --bin native_example -- \
      --gui --no-network --seed-image target/seed/native/seed.img
    ```

    [Follow the native tutorial →](/tutorials/native/)

  </TabItem>
</Tabs>

## Why Xila

<CardGrid>
  <Card title="Lightweight" icon="rocket">
    Designed for resource-constrained hardware with predictable memory bounds,
    small binary sizes, and a `no_std` kernel foundation.
  </Card>
  <Card title="Safe" icon="approve-check">
    Built with Rust's memory safety guarantees, typed device interfaces, and
    isolated task boundaries.
  </Card>
  <Card title="Portable" icon="laptop">
    Provides uniform virtual file system, task, and device abstractions across
    desktop Linux, web browsers, and bare-metal ARM microcontrollers.
  </Card>
  <Card title="Modular" icon="puzzle">
    Executes sandboxed WebAssembly (Wasm) guest applications in isolated Wasmi
    environments.
  </Card>
</CardGrid>
