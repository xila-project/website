The Platforms `drivers_wasm` crate supplies drivers for the WebAssembly (Wasm) browser runtime.

## Context

The browser runtime targets `wasm32-unknown-unknown`. Guest applications use a separate target, `wasm32-wasip1`.

## How it works

The browser example uses an Origin Private File System (OPFS) drive as block storage for its LittleFS root. Canvas display, keyboard, and mouse connect to the graphics manager.

It mounts time and CPU information at `/devices/time/clock` and `/devices/compute/informations`. Its HTTP device is mounted at both `/devices/network/http_client` and `/devices/network/https_client`. Audio playback is mounted at `/devices/audio/playback` after the user enables audio.

## Design choices and trade-offs

The drive uses a memory cache and asynchronous persistence. Browser storage restrictions and persistence behavior are described in [Browser storage](/explanation/browser-storage/). Browser HTTP uses Fetch, so browser restrictions apply.
