title: "Libraries"
docType: explanation
description: "Xila's reusable Rust contracts, helpers, and implementations shared across the operating system."
---

Xila libraries define reusable contracts, protocols, algorithms, adapters, and concrete implementations. They supply shared capabilities to the rest of the operating system. No library owns an independent runtime service.

- [ABI](/explanation/architecture/libraries/abi/): Native application function table, SDK, and executable loading.
- [Audio](/explanation/architecture/libraries/audio/): PCM audio formats, device commands, bounded queues, mixing, and VFS integration.
- [Authentication](/explanation/architecture/libraries/authentication/): User and group authentication, password hashing, and file-based account persistence.
- [Bootsplash](/explanation/architecture/libraries/bootsplash/): Startup logo animation and timeline management using the graphics subsystem.
- [Debug protocol](/explanation/architecture/libraries/debug_protocol/): Framing, request models, and validation for headless debugging and UI automation.
- [Device](/explanation/architecture/libraries/device/): Typed control contracts for Xila devices and their drivers.
- [Executable](/explanation/architecture/libraries/executable/): Executable contracts, execution context, standard streams, and task launching.
- [File system](/explanation/architecture/libraries/file_system/): Architectural contract layer for storage nodes, files, directories, and device endpoints.
- [Firmware update](/explanation/architecture/libraries/firmware_update/): Firmware update transactions for staging, verifying, and activating images.
- [HTTP](/explanation/architecture/libraries/http/): Bounded HTTP/1.1 response parsing, in-place chunked decoding, and framing.
- [Internationalization](/explanation/architecture/libraries/internationalization/): Build-time locale selection, catalog structure, and embedded-i18n integration.
- [Little FS](/explanation/architecture/libraries/little_fs/): Concrete LittleFS backend implementing Xila file system contracts.
- [Neural network](/explanation/architecture/libraries/neural_network/): Model loading and inference contracts for neural network devices.
- [Peripherals](/explanation/architecture/libraries/peripherals/): Embedded-HAL GPIO contracts, pin configuration, and mock implementations.
- [Shared](/explanation/architecture/libraries/shared/): Portable cross-cutting primitives, unit conversions, and layout-based type erasure.
- [Synchronization](/explanation/architecture/libraries/synchronization/): Synchronization primitives, async locks, and portable reference-counted pointers.
- [Testing](/explanation/architecture/libraries/testing/): In-memory test environment, mock hardware devices, and integration test helpers.
- [Verification](/explanation/architecture/libraries/verification/): Shared SHA-256 and Ed25519 verification library.
