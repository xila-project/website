This guide shows how to write and validate a Xila documentation page.

## Before you begin

- Install Node.js and npm, and obtain the [website repository](https://github.com/xila-project/website).
- Read the repository's `AGENTS.md` and `docs/templates/README.md`. Check source code for each technical claim.

## Steps

1. In the website repository root, install locked dependencies in a host shell:

   ```sh
   npm ci
   ```

2. Choose a page type and its template. Tutorials teach one path; how-to guides solve a task; reference pages describe exact interfaces; explanations describe concepts and trade-offs.
3. Give substantive pages a title, `docType`, and one-sentence description in frontmatter. Use sentence-case headings, starting at level two. Follow the section order in the chosen template.
4. Write direct, short sentences. Introduce commands with their working directory and context, use language-tagged code blocks, and link related pages with root-relative paths ending in `/`. Use the reference components for source and Rustdoc links. Introduce diagrams and explain their relationships in text.
5. In the website repository root, start a local preview in a host shell:

   ```sh
   npm run docs:dev
   ```

6. In the website repository root, build Rustdoc when needed and run the site checks in a host shell:

   ```sh
   npm run docs:rustdoc
   npm run check
   ```

   `check` runs reference tests, formatting, the site build, and the documentation validator. The validator can also run separately as `npm run docs:validate`.

## Verify the result

The checks exit successfully. Review the rendered page and confirm that source and internal links resolve.
