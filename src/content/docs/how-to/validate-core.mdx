This guide shows how to validate a change in Core.

## Before you begin

- Set up the [development environment](/how-to/setup-development/) and install Core's native build dependencies.
- Read the [Core contributor rules](https://github.com/xila-project/core/blob/main/AGENTS.md).

## Steps

1. In the Core repository root, check formatting in a host shell:

   ```sh
   mise run format:rust -- --check
   mise run format:toml -- --check
   ```

2. In the Core repository root, check host and guest targets, lint them, and test the workspace:

   ```sh
   mise run check:all
   mise run clippy:all
   mise run test:workspace
   ```

3. In the Core repository root, run `mise run localization:check` for localization changes and `mise run test:fonts` for font changes. Consult [Development commands](/reference/development-commands/) for focused tasks.

## Verify the result

Each command exits successfully. Core CI's required gate depends on quality, verification, host, Wasm, ABI and localization jobs; local host checks do not establish hardware correctness.
