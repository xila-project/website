This guide shows how to add a `shortcut.json` launcher descriptor to an application bundle so that Xila's graphical shell discovers and launches the application.

## Before you begin

- A compiled `wasm32-wasip1` guest binary, as described in [Build a guest application](/how-to/build-guest/).
- An application bundle directory that you install under `/applications/bundles/<identifier>/`.

## Steps

### Create the shortcut descriptor

1. In the root of the bundle directory, create a file named `shortcut.json`.
2. Populate `shortcut.json` with the required fields:

   ```json
   {
     "$schema": "https://raw.githubusercontent.com/xila-project/applications/main/schemas/shell-shortcut.schema.json",
     "name": "Calculator",
     "command": "/applications/executables/wasm",
     "arguments": ["@bundle/executables/calculator.wasm"],
     "terminal": false,
     "icon_string": "Ca",
     "icon_color": [158, 158, 158]
   }
   ```

   All six launcher properties are required:

   | Property      | Format                      | Description                                                      |
   | ------------- | --------------------------- | ---------------------------------------------------------------- |
   | `name`        | String, 1-128 characters    | Display name shown in the application drawer                     |
   | `command`     | String, 1-256 characters    | Path to the executable; `@bundle/` prefix is supported           |
   | `arguments`   | Array of up to 24 strings   | Command arguments; `@bundle/` elements are expanded by the shell |
   | `terminal`    | Boolean                     | Declares whether the application runs in a terminal              |
   | `icon_string` | String, 1-8 characters      | Monogram text rendered inside the icon                           |
   | `icon_color`  | Array of 3 integers (0-255) | RGB color array for the icon background                          |

### Install the bundle structure

1. Place the executable inside the bundle directory, matching the path specified in `arguments`:
   ```text
   /applications/bundles/xila.calculator/
     shortcut.json
     executables/
       calculator.wasm
   ```
2. Copy or mount the bundle directory into `/applications/bundles/` in Xila's virtual file system (VFS).

## Verify the result

1. In Xila, open the graphical shell's application drawer.
2. Confirm that an icon displaying your `icon_string` and `icon_color` appears with the application `name`.
3. Select the icon to launch the application.

## Troubleshooting

| Symptom                                | Cause                                                  | Fix                                                                           |
| -------------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------- |
| Shortcut does not appear in the drawer | Missing required properties or invalid JSON syntax     | Verify that all six fields are present and conform to the schema              |
| Application fails to launch            | Path in `arguments` does not exist inside the bundle   | Ensure paths with `@bundle/` point to files within the bundle directory       |
| File path rejected by the shell        | The path contains `..`, empty segments, or backslashes | Use clean relative paths under `@bundle/` without parent directory navigation |
