Xila mounts the GPIO pins of a board as character devices under `/devices/gpio/`. This guide shows how to list the pins of your board, read a pin state, and write an output level from the command-line shell. [Install Xila on a board](/how-to/install-on-a-board/) first, then log in on the serial console. For the features of each board, see [Supported hardware](/reference/supported-hardware/).

## Before you begin

- Xila installed on the board and a logged-in command-line shell. See [Install Xila on a board](/how-to/install-on-a-board/).
- A board whose firmware mounts GPIO devices. The tabs below list the devices of each board.

The shell has no command that configures a GPIO pin. Applications use the control commands of the GPIO device. See [Peripherals](/explanation/architecture/libraries/peripherals/).

### Read a pin state

1. In the Xila shell, read the device file of the pin:

```text
cat /devices/gpio/d13
```

The device outputs `0` or `1` followed by a newline.

### Write an output level

1. In the Xila shell, write to the device file of the pin to update its output level:

```text
# Turn on the yellow LED:
echo 1 > /devices/gpio/d13

# Turn off the yellow LED:
echo 0 > /devices/gpio/d13
```

For the active-low RGB LEDs of the Arduino Nano 33 BLE, writing `0` turns the LED on, and writing `1` turns it off:

```text
# Turn on the red LED:
echo 0 > /devices/gpio/led_red

# Turn off the red LED:
echo 1 > /devices/gpio/led_red
```

Writing any character other than `0` or `1` (surrounded by optional whitespace) returns an error.

## Verify the result

1. In the serial terminal, verify that the shell prompt (`user@host:directory$`) appears after logging in.
2. On the Arduino Nano 33 BLE, run `echo 1 > /devices/gpio/d13` and observe that the yellow onboard LED lights up.
3. Run `echo 0 > /devices/gpio/d13` and observe that the yellow LED turns off.
