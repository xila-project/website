The Xila host API comprises the portable Rust crates in **[Xila Core](https://github.com/xila-project/core)** (`Xila-Project/core`), re-exported through the <HostReference crate="xila" /> façade crate (<CodeReference path="core/src/lib.rs" />), together with the host-side WebAssembly runtime and native executables in **[Xila Applications](https://github.com/xila-project/applications)**. Platform-specific hardware and OS drivers live in **[Xila Platforms](https://github.com/xila-project/platforms)**.

Use the interactive Rustdoc viewer below to browse crate, module, trait, struct, and function signatures across the Core workspace, or jump directly to a specific crate in the [workspace inventory](#core-workspace-crate-inventory).

## Façade crate (`xila`) and Cargo features

The `xila` package in <CodeReference path="core/Cargo.toml" /> is a `#![no_std]` façade that re-exports the Core subsystems and libraries under unified module names.

| Cargo feature                 | Enabled re-exports / behavior                                                                                                                                                                                                                                                                  |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| _(default)_                   | Always-available subsystems (`task`, `virtual_file_system`, `network`, `users`, `time`, `log`, `memory`) and foundational libraries (`file_system`, `little_fs`, `executable`, `authentication`, `abi_declarations`, `shared`, `synchronization`, `internationalization` via `embedded_i18n`). |
| `graphics`                    | Re-exports <HostReference crate="graphics" /> (LVGL 9.6 windowing, display, input, theme, and font management).                                                                                                                                                                                |
| `graphics_rendering_argb8888` | Configures `graphics` for 32-bit `ARGB8888` software rendering.                                                                                                                                                                                                                                |
| `graphics_rendering_xrgb8888` | Configures `graphics` for 32-bit `XRGB8888` software rendering (used by native Linux, headless, and browser targets).                                                                                                                                                                          |
| `graphics_rendering_rgb565`   | Configures `graphics` for 16-bit `RGB565` rendering.                                                                                                                                                                                                                                           |
| `graphics_rendering_rgb888`   | Configures `graphics` for 24-bit `RGB888` rendering.                                                                                                                                                                                                                                           |
| `audio`                       | Re-exports <HostReference crate="audio" /> (bounded PCM stream contracts and software mixer).                                                                                                                                                                                                  |
| `neural_network`              | Re-exports <HostReference crate="neural_network" /> and <HostReference crate="drivers_neural_network" /> (synchronous inference backend trait and VFS character-device adapter).                                                                                                               |
| `bootsplash`                  | Re-exports <HostReference crate="bootsplash" /> (Monogram startup splash screen animation). Requires `graphics`.                                                                                                                                                                               |
| `abi_definitions`             | Re-exports <HostReference crate="abi_definitions" /> (exported `#[unsafe(no_mangle)] extern "C"` allocator, string, time, VFS, and user symbols linked by C libraries such as LittleFS and LVGL).                                                                                              |

- **Applications (`Xila-Project/applications`)**:

## Building host documentation locally

From a `core` checkout with [mise](https://mise.jdx.dev/) and locked npm dependencies installed (`npm ci` for `lv_font_conv`):

```sh
mise trust
mise run deps:npm
RUSTDOCFLAGS="--deny warnings" mise run docs:host -- --no-deps
```

`docs:host` runs `cargo doc` across the full Core workspace for `x86_64-unknown-linux-gnu`; its exact feature list is defined in Core's <CodeReference path="mise.toml" />. The HTML entry point is `target/x86_64-unknown-linux-gnu/doc/xila/index.html`. The website's `npm run docs:rustdoc` runs these same Core tasks.
