The host Rustdoc documents the Rust crates in the Core workspace. Core's `docs:host` mise task compiles the documentation for the `x86_64-unknown-linux-gnu` target. Run `mise run docs:host -- --no-deps` in the Core repository. The website stages the documentation into the build with `npm run docs:rustdoc` (or `mise run documentation:rustdoc` in the website repository). See `scripts/build-rustdoc.mjs` and `mise.toml`.

## Cargo features

The `xila` crate in <CodeReference path="core/Cargo.toml" /> is a `#![no_std]` façade (<CodeReference path="core/src/lib.rs" />). It re-exports Core workspace subsystems and libraries under unified names. These modules, among others, are always available without optional features: `authentication`, `executable`, `file_system`, `internationalization` (via `embedded-i18n`), `little_fs`, `log`, `memory`, `shared`, `synchronization`, `task`, `time`, `users`, and `virtual_file_system`.

| Feature                       | Default | Effect                                                                                                   |
| ----------------------------- | ------- | -------------------------------------------------------------------------------------------------------- |
| `network`                     | Yes     | Re-exports <HostReference crate="network" /> and enables network support in `executable`                 |
| `audio`                       | No      | Re-exports <HostReference crate="audio" /> (PCM stream contracts and software mixer)                     |
| `bootsplash`                  | No      | Re-exports <HostReference crate="bootsplash" /> (startup splash screen animation)                        |
| `executable_building`         | No      | Enables executable building utilities in <HostReference crate="executable" />                            |
| `graphics`                    | No      | Re-exports <HostReference crate="graphics" /> and enables graphics support in `executable`               |
| `graphics_rendering_rgb565`   | No      | Enables `graphics` and configures 16-bit RGB565 color depth rendering                                    |
| `graphics_rendering_xrgb8888` | No      | Enables `graphics` and configures 32-bit XRGB8888 color depth rendering                                  |
| `neural_network`              | No      | Re-exports <HostReference crate="neural_network" /> and <HostReference crate="drivers_neural_network" /> |
| `native-dev`                  | No      | Enables raw ELF native executables in `executable` (the platform must also register the native format)   |
| `task_metrics`                | No      | Enables task and executor activity metrics in <HostReference crate="task" />                             |

## Generation

Core's `docs:host` mise task generates the host Rustdoc. Run `mise run docs:host -- --no-deps`; the task is defined in <CodeReference path="mise.toml" />. It invokes `cargo doc --workspace` for the target `x86_64-unknown-linux-gnu` with the features `xila/graphics`, `xila/graphics_rendering_xrgb8888`, `xila/audio`, `xila/neural_network`, `xila/bootsplash`, and `xila-testing/graphics`.

When `CARGO_TARGET_DIR` is unset, Cargo writes the HTML output to `target/x86_64-unknown-linux-gnu/doc/xila/index.html`, relative to the Core repository root. The website stages this output into `dist/rustdoc/host/` with `npm run docs:rustdoc` (`mise run documentation:rustdoc` in the website repository). See `scripts/build-rustdoc.mjs` and `mise.toml`.

For the complete list of development tasks, see [Development commands](/reference/development-commands/).
