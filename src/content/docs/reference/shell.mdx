This page provides the authoritative reference for the command syntax, execution rules, built-in commands, and resource limits implemented by Xila's command-line shell (<HostReference repo="applications" crate="command_line_shell" />, <CodeReference repo="applications" path="executables/shell/command_line/src/commands/mod.rs" />).

## Invocation

The shell executable accepts the following invocation modes:

| Invocation             | Arguments          | Description                                                                                             |
| ---------------------- | ------------------ | ------------------------------------------------------------------------------------------------------- |
| Interactive mode       | None               | Authenticates the user if unauthenticated and presents an interactive prompt (`user@host:directory$ `). |
| Command string         | `-c "COMMAND"`     | Parses and executes the provided command string, including pipelines and redirections.                  |
| Script file            | `-s PATH`          | Reads and executes lines sequentially from a file in the virtual file system (VFS).                     |
| Programmatic arguments | `COMMAND [ARG]...` | Executes the command and arguments literally without re-tokenizing or performing shell expansion.       |

Nested script executions track recursion depth using the `XILA_SHELL_DEPTH` environment variable. Invocations exceeding the maximum depth of four stop with exit status 2.

## Command composition

The shell parser splits input lines into pipeline stages and conditional execution chains using standard shell operators:

| Operator        | Syntax             | Description                                                                                  |
| --------------- | ------------------ | -------------------------------------------------------------------------------------------- |
| Pipe            | `stage1 \| stage2` | Connects stdout of `stage1` to stdin of `stage2` through an unnamed in-memory VFS pipe.      |
| Logical AND     | `cmd1 && cmd2`     | Executes `cmd2` only if `cmd1` terminates with exit status 0.                                |
| Logical OR      | `cmd1 \|\| cmd2`   | Executes `cmd2` only if `cmd1` terminates with a non-zero exit status.                       |
| Sequential      | `cmd1 ; cmd2`      | Executes `cmd1`, followed by `cmd2` regardless of exit status.                               |
| Background      | `cmd &`            | Spawns the pipeline as a detached task with stdin redirected to `/devices/standard_io/null`. |
| Input redirect  | `< PATH`           | Redirects standard input from the file at `PATH`.                                            |
| Output redirect | `> PATH`           | Truncates and writes standard output to the file at `PATH`.                                  |
| Output append   | `>> PATH`          | Appends standard output to the file at `PATH`.                                               |
| Error redirect  | `2> PATH`          | Truncates and writes standard error to the file at `PATH`.                                   |
| Error append    | `2>> PATH`         | Appends standard error to the file at `PATH`.                                                |
| Comment         | `# TEXT`           | Ignores all characters from `#` to the end of the line when `#` begins a word.               |

## Variable expansion

The shell performs parameter and status expansion prior to command execution:

- `$NAME` or `${NAME}`: Expands to the value of the task environment variable `NAME`. Unset variables expand to an empty string.
- `$?`: Expands to the decimal exit status of the most recently executed foreground command.
- Double quotes (`"..."`): Preserve literal whitespace while enabling variable expansion and escape sequences for `\$`, `\"`, and `\\`.
- Single quotes (`'...'`): Preserve all enclosed characters literally without variable expansion or escape sequences.
- Command substitution: Constructing command substitutions with `$(...)` or backticks is unsupported and triggers a syntax error.

## Resolution

When a command line does not match an internal built-in, the shell resolves an external executable target:

1. **Path contains `/`**: If the command contains any forward slash, the shell treats it as a path. Absolute paths (`/applications/executables/...`) execute directly. Relative paths are resolved against the task's `Current_directory` environment variable.
2. **Path contains no `/`**: The shell reads the colon-separated directory list stored in the `Paths` environment variable (for example, `/applications/executables`). It scans each directory in order and executes the first matching executable file.
3. **Execution dispatch**: The resolved path is passed to <HostReference crate="executable" kind="fn" symbol="execute" />, which verifies permissions and spawns the target task. If no matching command is found, the shell emits exit status 127.

## Built-in commands

The command-line shell provides the following built-in commands:

| Command       | Arguments                                                                    | Description                                                                                                   |
| ------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `true`        |                                                                              | Return success (status 0) without output.                                                                     |
| `false`       |                                                                              | Return status 1 without output.                                                                               |
| `exit`        | `[STATUS]`                                                                   | Exit the shell, optionally returning `STATUS` (defaults to previous status).                                  |
| `cd`          | `[PATH]`                                                                     | Change current working directory to `PATH` (or root if omitted).                                              |
| `echo`        | `[TEXT]...`                                                                  | Print arguments separated by spaces followed by a newline.                                                    |
| `ls`          | `[-l\|--long] [PATH]`                                                        | List directory entries in short format or long format with permissions, owner, and size.                      |
| `ln`          | `TARGET LINK`                                                                | Create a symbolic link at `LINK` pointing to `TARGET`.                                                        |
| `readlink`    | `LINK`                                                                       | Print the target destination of the symbolic link `LINK`.                                                     |
| `clear`       |                                                                              | Clear the terminal display using the ANSI escape sequence `\x1b[2J`.                                          |
| `cat`         | `[FILE]...`                                                                  | Concatenate and print file contents or standard input (`-`).                                                  |
| `grep`        | `PATTERN [FILE]...`                                                          | Print lines matching literal string `PATTERN` from files or standard input (`-`).                             |
| `stat`        | `PATH`                                                                       | Display file metadata, kind, size, permissions, and modification timestamp.                                   |
| `mkdir`       | `PATH`                                                                       | Create a directory at `PATH`.                                                                                 |
| `export`      | `NAME=VALUE`                                                                 | Set an environment variable on the current task.                                                              |
| `unset`       | `NAME`                                                                       | Remove an environment variable from the current task.                                                         |
| `rm`          | `PATH`                                                                       | Remove the file at `PATH`.                                                                                    |
| `rmdir`       | `PATH`                                                                       | Remove the empty directory at `PATH`.                                                                         |
| `web_request` | `[-m METHOD] [-h HEADER]... [-b BODY \| -f BODY_FILE] URL`                   | Send an HTTP/HTTPS request via `/devices/network/http_client` or `https_client` (requires `network` feature). |
| `dns_resolve` | `[-a\|--a] [-A\|--aaaa] [-c\|--cname] [-n\|--ns] [-s\|--soa] DOMAIN`         | Query DNS records for `DOMAIN` (requires `network` feature).                                                  |
| `ping`        | `[-c COUNT] [-t TIMEOUT] [-s SIZE] TARGET`                                   | Send ICMP echo requests to `TARGET` (default count 4, timeout 5s, size 56 bytes; requires `network` feature). |
| `ip`          | `COMMAND`                                                                    | Display network interface addresses or routing tables (`ip addr`, `ip route`; requires `network` feature).    |
| `pwd`         |                                                                              | Print the current working directory path.                                                                     |
| `realpath`    | `PATH...`                                                                    | Print canonical absolute paths for existing files and directories.                                            |
| `printenv`    | `[NAME]`                                                                     | Print the value of environment variable `NAME` or all variables.                                              |
| `which`       | `COMMAND`                                                                    | Search directories in `Paths` to locate the executable path for `COMMAND`.                                    |
| `wc`          | `[-c\|--characters] [-w\|--words] [-l\|--lines] [-L\|--longest-line] [PATH]` | Count characters, words, lines, and longest line length for a file or standard input.                         |
| `head`        | `[-n\|--lines N] PATH`                                                       | Print the first `N` lines of a file (defaults to 10).                                                         |
| `tail`        | `[-n\|--lines N] PATH`                                                       | Print the last `N` lines of a file (defaults to 10).                                                          |
| `help`        | `[COMMAND]`                                                                  | List all built-in commands or print detailed usage for `COMMAND`.                                             |
| `tree`        | `[-L\|--level DEPTH] [PATH]`                                                 | Display a recursive directory tree up to `DEPTH` levels (defaults to 32).                                     |
| `find`        | `[-n\|--name NAME] [-t\|--type TYPE] [-d\|--max-depth DEPTH] [PATH]`         | Search a directory tree matching name or entry type up to `DEPTH` (defaults to 32).                           |
| `mv`          | `SOURCE DESTINATION`                                                         | Rename or move a file or directory within the same mounted filesystem.                                        |
| `cp`          | `SOURCE DESTINATION`                                                         | Copy a file to a destination path or directory.                                                               |
| `sleep`       | `DURATION`                                                                   | Pause execution for a nonnegative integer duration with unit suffix (`ms`, `s`, `m`, `h`).                    |
| `chmod`       | `MODE PATH`                                                                  | Change octal permissions (000–777) of the file or directory at `PATH`.                                        |
| `touch`       | `FILE...`                                                                    | Create missing files and update modification timestamps.                                                      |

## Limits

The shell enforces strict resource boundaries:

| Limit                | Value       | Description                                                                                              |
| -------------------- | ----------- | -------------------------------------------------------------------------------------------------------- |
| Input buffer         | 4,096 bytes | Maximum raw byte length of an interactive command line or script line (`MAX_INPUT_BYTES`).               |
| Token count          | 256         | Maximum number of parsed tokens per command line (`MAX_TOKENS`).                                         |
| Expansion buffer     | 8,192 bytes | Maximum length of a command line after environment variable and status expansion (`MAX_EXPANDED_BYTES`). |
| Pipeline buffer      | 512 bytes   | Capacity of the unnamed in-memory pipe ring buffer connecting pipeline stages (`PIPE_BYTES`).            |
| Background tasks     | 8           | Maximum concurrent background jobs running simultaneously (`MAX_BACKGROUND_JOBS`).                       |
| Nesting depth        | 4           | Maximum recursion depth for nested shell script invocations (`MAX_SHELL_DEPTH`).                         |
| Tree traversal depth | 32          | Maximum recursion depth for `tree` and `find` commands.                                                  |

## Errors

Commands and script invocations terminate with specific numeric status codes:

| Status code | Cause                 | Description                                                                                               |
| ----------- | --------------------- | --------------------------------------------------------------------------------------------------------- |
| `0`         | Success               | Command completed successfully.                                                                           |
| `1`         | Command error         | Built-in command reported an execution failure, stream flush failed, or background job limit reached.     |
| `2`         | Syntax or usage error | Command line exceeded length limits, unclosed quotes, invalid expansion syntax, or script file I/O error. |
| `127`       | Command not found     | Command could not be resolved in built-in registry, explicit path, or `Paths` directory search.           |
