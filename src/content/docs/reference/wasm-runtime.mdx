The `xila-wasm` crate in the Applications repository (<CodeReference repo="applications" path="executables/wasm/src/host/mod.rs" />) implements the WebAssembly (Wasm) host runtime for Xila. It uses the <DocsRsReference crate="wasmi" /> 2.0.0 engine.

## Command syntax

The Wasm runner is mounted in the virtual file system (VFS) at `/applications/executables/wasm`:

```text
/applications/executables/wasm [options] <path> [-- [guest-arguments...]]
```

| Option                | Default   | Description                                      |
| --------------------- | --------- | ------------------------------------------------ |
| `<path>`              | Required  | Absolute VFS path to the `wasm32-wasip1` module  |
| `--instruction-limit` | `100_000` | Fuel quantum per execution slice before yielding |
| `--stack-size`, `-s`  | `4096`    | Stack size parameter parsed by the runner        |
| `--help`, `-h`        | None      | Prints command usage information                 |
| `--version`, `-v`     | None      | Prints version information                       |

Arguments after `--` go directly to the guest application. The guest reads them through standard argument APIs (`std::env::args`).

## Cargo features

The `xila-wasm` package provides the following Cargo features (<CodeReference repo="applications" path="executables/wasm/Cargo.toml" />):

| Feature         | Default | Effect                                                                         |
| --------------- | ------- | ------------------------------------------------------------------------------ |
| `host`          | Yes     | Compiles the Wasmi interpreter and Xila executable integration                 |
| `guest`         | No      | Compiles guest helpers without the Wasmi interpreter                           |
| `graphics`      | No      | Compiles LVGL graphics dispatch and guest bindings                             |
| `c_bindings`    | No      | Compiles C extern wrappers and generates `xila_graphics.h`                     |
| `memory_32`     | Yes     | Configures 32-bit guest word translation (`wasm32`)                            |
| `memory_64`     | No      | Configures 64-bit guest word translation (`wasm64`)                            |
| `default_guest` | No      | Convenience bundle enabling `guest`, `graphics`, `c_bindings`, and `memory_32` |

## WASI Preview 1 imports

The host runtime registers the following `wasi_snapshot_preview1` functions in the module linker (<CodeReference repo="applications" path="executables/wasm/src/host/wasi/register.rs" />):

| Function                | Domain      | Description                                                                 |
| ----------------------- | ----------- | --------------------------------------------------------------------------- |
| `args_get`              | Environment | Copies argument pointers and strings into guest memory                      |
| `args_sizes_get`        | Environment | Returns argument count and total string buffer size                         |
| `environ_get`           | Environment | Copies environment variable pointers and strings into guest memory          |
| `environ_sizes_get`     | Environment | Returns environment variable count and total string buffer size             |
| `clock_res_get`         | Clocks      | Returns the resolution of the specified clock                               |
| `clock_time_get`        | Clocks      | Queries the current timestamp for realtime or monotonic clocks              |
| `fd_close`              | Descriptors | Closes an open file descriptor                                              |
| `fd_control`            | Descriptors | Issues a typed control command to a VFS character device                    |
| `fd_fdstat_get`         | Descriptors | Queries descriptor flags and access rights                                  |
| `fd_filestat_get`       | Descriptors | Queries file statistics for an open descriptor                              |
| `fd_prestat_get`        | Descriptors | Returns preopened directory descriptor capabilities                         |
| `fd_prestat_dir_name`   | Descriptors | Returns the path of a preopened directory                                   |
| `fd_read`               | Descriptors | Reads bytes from a descriptor into scatter/gather vectors                   |
| `fd_readdir`            | Descriptors | Reads directory entries from an open directory descriptor                   |
| `fd_seek`               | Descriptors | Adjusts the read/write offset of an open file descriptor                    |
| `fd_write`              | Descriptors | Writes bytes from scatter/gather vectors to a descriptor                    |
| `path_create_directory` | File system | Creates a directory at the given path                                       |
| `path_filestat_get`     | File system | Queries file statistics for a path relative to a directory                  |
| `path_open`             | File system | Opens a file or directory relative to a directory descriptor                |
| `path_readlink`         | File system | Reads the target of a symbolic link                                         |
| `path_symlink`          | File system | Creates a symbolic link relative to a directory descriptor                  |
| `path_unlink_file`      | File system | Removes a regular file or link relative to a directory descriptor           |
| `poll_oneoff`           | Polling     | Suspends execution until clock subscription timers expire                   |
| `proc_exit`             | Process     | Terminates execution with a numeric exit status                             |
| `random_get`            | Randomness  | Fills a guest memory buffer with random bytes from `/devices/random/source` |
| `sched_yield`           | Scheduling  | Yields execution cooperatively to the task scheduler                        |

## Environment variables

When launching an application bundle or standard executable, the host runner configures three environment variables pointing to user-isolated directories:

| Variable                         | Path                                             | Description                           |
| -------------------------------- | ------------------------------------------------ | ------------------------------------- |
| `XILA_APPLICATION_CONFIGURATION` | `/users/<user>/applications/<app>/configuration` | Application configuration directory   |
| `XILA_APPLICATION_DATA`          | `/users/<user>/applications/<app>/data`          | Persistent application data directory |
| `XILA_APPLICATION_CACHE`         | `/users/<user>/applications/<app>/cache`         | Ephemeral application cache directory |

## Browser capabilities

The Platforms browser example compiles the Xila host for `wasm32-unknown-unknown` and executes `wasm32-wasip1` guest applications within Wasmi in the web browser:

| Capability      | Behavior                                                                     |
| --------------- | ---------------------------------------------------------------------------- |
| Host target     | Compiled to `wasm32-unknown-unknown`                                         |
| Guest target    | Compiled to `wasm32-wasip1`                                                  |
| Storage         | Requires Origin Private File System (OPFS), `createWritable`, and Web Locks  |
| Disk format     | 16 MiB MBR and LittleFS image                                                |
| Disk names      | Uses `xila_YYYY-MM-DD.img` or the default `xila_drive.img`                   |
| Disk management | Managed through the Xila Help panel                                          |
| Saves           | Persisted at boot, on normal shutdown, and periodically when dirty           |
| Guest execution | Executes preinstalled bundled guests; external guest upload is not supported |
| Networking      | Uses browser Fetch under CORS restrictions without raw sockets               |

## Limits

| Parameter                 | Limit                                         | Source                                                                  |
| ------------------------- | --------------------------------------------- | ----------------------------------------------------------------------- |
| Fuel quantum per slice    | 100,000 instructions                          | `instruction_limit` in `executables/wasm/src/host/main.rs`              |
| Compilation mode          | Eager                                         | `CompilationMode::Eager` in `executables/wasm/src/host/main.rs`         |
| Preopened descriptors     | fd 0 (stdin), 1 (stdout), 2 (stderr), 3 (`/`) | `wasi::context` in `executables/wasm/src/host/main.rs`                  |
| Clock poll subscriptions  | 64                                            | `MAX_SUBSCRIPTIONS` in `executables/wasm/src/host/wasi/poll_memory.rs`  |
| Polling sleep interval    | 50 ms max per sleep chunk                     | `executables/wasm/src/host/execution.rs`                                |
| Control command payload   | 256 bytes                                     | `MAX_CONTROL_PAYLOAD` in `executables/wasm/src/host/wasi/file.rs`       |
| Control command alignment | 16 bytes                                      | `CONTROL_PAYLOAD_ALIGNMENT` in `executables/wasm/src/host/wasi/file.rs` |

## Errors

| Error                           | Condition                                          | Effect                                                      |
| ------------------------------- | -------------------------------------------------- | ----------------------------------------------------------- |
| `NotAWasmFile`                  | The module path is not a regular file              | Prints error and exits with code 1                          |
| Argument parsing error          | Unknown options or invalid flag syntax             | Prints error message to stdout/stderr and exits with code 1 |
| Missing `_start`                | The module does not export `_start: () -> ()`      | Returns runtime error and exits with code 1                 |
| Nonzero guest exit              | The guest calls `proc_exit(code)` with `code != 0` | Returns the exit code clamped to `1..=255`                  |
| Trap or fuel exhaustion failure | Unhandled trap or execution error                  | Prints trap details to stderr and exits with code 1         |
