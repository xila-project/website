These tasks come from each repository's mise configuration. Run `mise run <task>` in the named repository root; CI and development task availability depends on the selected mise environment.

## Dependency inventory

The workspace [Nanobom workflow](https://github.com/xila-project/workspace/blob/main/.github/workflows/nanobom.yml) accepts optional `project`, `scan-path` and `fail-on` inputs. It requires the `NANOBOM_TOKEN` secret. Callers may trigger it on pushes to main, schedules or manual dispatch, not pull requests. The package manager repository calls it.
