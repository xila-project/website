In this tutorial, you create a reference disk image that contains the released WebAssembly (Wasm) applications, and you start the native runtime on desktop Linux. At the end, you have an interactive Xila desktop on your display.

## Before you begin

- An x86_64 Linux system with an active Wayland or X11 session. The package step uses `apt`. A Debian-based distribution, for example Debian or Ubuntu, is the simplest choice.
- [Git](https://git-scm.com/), to clone the Platforms repository.
- [mise](https://mise.jdx.dev/), which installs the Rust toolchain and the other tools that each task needs.
- [Node.js](https://nodejs.org/) and npm, for the font converter used by the graphics build.
- A network connection. The disk image step downloads the released application packages.

## Prepare the Platforms repository

1. Clone the [Platforms repository](https://github.com/xila-project/platforms) and enter it:

   ```sh
   git clone https://github.com/xila-project/platforms.git
   cd platforms
   ```

2. Trust the repository's mise configuration:

   ```sh
   mise trust
   ```

3. Install the native host packages (for example ALSA, Wayland and X11 development files):

   ```sh
   mise bootstrap packages apply --manager apt
   ```

4. Install the locked npm dependencies for the font converter:

   ```sh
   npm ci
   ```

   npm prints a summary of the installed packages.

## Create a reference disk image

1. In the Platforms repository root, create the seed image:

   ```sh
   mise run image:native
   ```

   The task downloads the released, signed application packages pinned in `tools/fs_image/profiles/bundles.lock.json`. The task then runs the `xila-fs-image` tool. When the task finishes, the 16 MiB LittleFS image is at `target/seed/native/seed.img`.

## Start the native runtime

1. In the Platforms repository root, run the native runtime:

```sh
cargo run -p xila-native-example --bin native_example -- --gui --no-network --seed-image target/seed/native/seed.img
```

Cargo builds the runtime. A window then opens with the Xila login screen. On first start, the runtime imports the seed into a new live disk at `./drive.img`.

## Log in and launch Calculator

1. In the user name field on the login screen, enter `administrator`. Leave the password field empty.
2. Click **Login**. The login screen closes, and the desktop loads with the dock and status bar.
3. Click the button with a 3 × 3 grid of squares on the dock to open the application drawer.
4. Click the **Calculator** icon. A window opens with the Calculator interface.
5. Click `1`, `+`, `2`, and `=`. The display updates to show `3`.
6. Click the close button in the top-right corner of the Calculator window. The window closes, returning to the empty desktop.

## Check your result

The Xila desktop is running. Calculator launched, evaluated an expression, and closed cleanly. The terminal prints log messages about task and device status.

To stop the native runtime, close the window or press `Ctrl+C` in the terminal. Your changes stay in `./drive.img`. The next start reuses that disk and ignores the seed. To start from a clean installation, pass a different path with `--disk-path`.
