In this tutorial, you run Xila in a web browser with the hosted demonstration at platforms.xila.dev. A guest application is a WebAssembly program that runs inside Xila. At the end, you have an Xila desktop in your browser with the Calculator guest application open.

## Before you begin

- A modern web browser that supports the Origin Private File System (OPFS) and the Web Locks API, for example Chromium, Chrome, or Firefox.
- An internet connection to reach `https://platforms.xila.dev/`.

## Open the hosted demonstration

1. In your web browser, navigate to the [Platforms hosted demonstration](https://platforms.xila.dev/). <DemonstrationLanguages />

The page loads the Xila runtime canvas and shows the login screen.

2. By default, the tab starts from the current seed image and keeps its changes in memory. To keep files between visits, turn on **Keep my files between visits** in the Xila Help panel. The panel then lets you create, select, or remove a saved disk in OPFS.

## Log in and launch Calculator

1. On the login screen, enter `administrator` in the user name field and leave the password blank.
2. Click **Login**. The login screen closes, and the Xila desktop appears with the dock.
3. Click the button with a 3 × 3 grid of squares on the dock to open the application drawer.
4. Click the **Calculator** icon. The Calculator application opens in a window on the canvas.
5. Click `1`, `+`, `2`, and `=`. The Calculator display updates to show `3`.
6. Click the close button in the top-right corner of the Calculator window. The window closes cleanly.

## Check your result

The browser canvas shows the Xila desktop. Calculator opens, responds to clicks, and evaluates arithmetic expressions. With the default memory disk, changes stay in the tab and are discarded when you reload or close it. A saved OPFS disk keeps them across visits.
